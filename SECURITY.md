# Security Policy

## Supported versions

Security fixes are applied to the latest published Astro Doctor packages, GitHub Action, VS Code extension, and documentation site. Older releases are not maintained separately.

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/santi020k/astro-doctor/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

Include the affected package or surface, reproduction steps, impact, and any suggested mitigation. You can expect an initial response within seven days. Confirmed reports will be addressed privately before a coordinated disclosure when practical.

## Scope

Reports about the CLI, lint plugins, GitHub Action, editor extension, release automation, and documentation site are welcome. Vulnerabilities in third-party services should be reported to their respective maintainers.
